# API Contract Standards

## 1. Versioning & Transport Conventions
- **Canonical Version**: `/api/v1` across frontend `httpClient` (`API_BASE_URL`) and Flask blueprints.
- **Content Types**: `application/json` for structured RPC/CRUD calls; `multipart/form-data` for file encryption/decryption; `application/octet-stream` for `.enc` and decrypted downloads.
- **Query Serialization**: `BaseRepository` + `interceptors.ts` serialize `params` via `Lazy.transform(..., "query")` omitting nullish/empty filter fields cleanly.
- **Timestamps**: ISO-8601 UTC strings generated by Python `datetime.isoformat()` and rendered locally by `useFormatters`.

## 2. TypeScript Contract Rules
- All DTO constructors accept `Record<string, unknown> = {}` (never `Record<string, any>`) and narrow every field at runtime via `src/utils/validators.ts`.
- Pagination (`DocumentListResponseDTO`) standardizes `{ items, total, page, per_page }`.
